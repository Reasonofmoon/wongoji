# lessons

- 칸 좌표는 `wongoji_render.export_layout`이 단일 출처다. 브라우저에서 다시 계산하지 않는다.
- 기각은 삭제가 아니라 되살림표다. kind를 stet로 바꿀 때 원문 배치(indent)를 함께 바꾸면 오류가 사라진다.
- 구간이 한 글자라도 겹친다고 LLM 항목을 버리면 이웃한 다른 종류 첨삭이 죽는다. 겹침은 같은 자리·같은 경계 또는 긴 쪽 대비 실질 겹침으로 판정한다.
- kiwi.space() 띄움표가 상한 없이 쌓이면 12칸을 채워 indent·replace가 지면에 못 앉는다. 띄움표 상한과 부호 종류 라운드로빈이 필요하다.
