# 한국어 표기 오류 유형 카탈로그

이 문서는 첨삭기가 **전수로 잡아야 하는 표기 오류**의 분류 체계다. 어떤 유형을 먼저
구현할지는 감이 아니라 실측이 정한다 — `말뭉치_근거.md`를 함께 읽는다. 각 유형은
`type` 코드로 골드 코퍼스와 평가 리포트에서 동일하게 쓰인다. 유형 코드를 바꾸면
과거 측정치와 비교할 수 없으므로, 추가는 하되 기존 코드는 재사용하지 않는다.

## 목차
- 층위 구분과 전수/초점 경계
- O1 소리 혼동 표기
- O2 어미·활용 오류
- O3 조사 오류
- O4 사이시옷
- O5 두음법칙·표준어
- O6 띄어쓰기
- O7 문장부호
- O8 원고지 형식
- O9 외래어 표기
- O10 구어체·통신 표기
- O11 단순 오타 (사전 미등재)
- C1~C4 내용 층위 (초점 대상)
- 오탐 억제 공통 원칙

## 층위 구분과 전수/초점 경계

| 층위 | 유형 | 지면 정책 | 담당 계층 |
|------|------|----------|----------|
| 표기 | O1~O10 | **전수 표시.** 상한에 걸려도 잘라내지 않고 다음 장으로 넘긴다 | 규칙 우선, 규칙이 못 잡는 것만 LLM |
| 내용 | C1~C4 | **초점 상한 유지.** 한 지면에 정해진 수만 | LLM |

전수와 초점을 가르는 이유: 표기 오류는 정답이 하나이고 학생이 다시 볼 때 규칙을
익힌다. 내용 첨삭은 정답이 여럿이고 많이 달수록 학생이 자기 글을 잃는다.

## O1 소리 혼동 표기

발음이 같거나 비슷해 형태를 잘못 고른 경우. 결정적 규칙으로 잡을 수 있는 것이 많다.

| 혼동쌍 | 판정 기준 |
|--------|----------|
| 되/돼 | `돼`는 `되어`의 준말. `되-` 뒤에 어미가 붙으면 `되`, 문장이 `돼`로 끝나면 `돼`. 치환 검사: `하/해`를 넣어 자연스러운 쪽을 고른다 |
| 안/않 | `안`은 부사(=아니), `않`은 용언 어간(=아니하). 뒤에 어미가 오면 `않`, 용언을 꾸미면 `안` |
| 왠/웬 | `왠`은 `왠지`뿐. 그 외 전부 `웬`(웬일, 웬만하다, 웬 사람) |
| 낫다/낮다/낳다 | 병이 낫다, 온도가 낮다, 아이를 낳다 |
| 맞추다/맞히다 | 서로 대어 보면 맞추다, 정답을 맞히다 |
| 늘리다/늘이다 | 수·양은 늘리다, 길이는 늘이다 |
| 바라다/바래다 | 소망은 바라다(`바라`), 색이 변하면 바래다 |
| 며칠/몇일 | `몇일`은 항상 틀림 |
| 오랜만/오랫만 | `오랫만`은 항상 틀림. `오랫동안`은 맞음 |
| 갔다/같다/갖다 | 가다/같이다/가지다의 활용 구분 |
| 던지/든지 | 과거 회상은 `던`, 선택은 `든` |
| 데/대 | 직접 경험은 `-데`, 전언은 `-대` |
| 로서/로써 | 자격은 `로서`, 수단·도구는 `로써` |
| 이따가/있다가 | 시간은 `이따가`, 존재는 `있다가` |

교정부호: `replace`(고침표). 한 글자 교체가 대부분이므로 span이 짧다.

## O2 어미·활용 오류

| 패턴 | 판정 기준 |
|------|----------|
| ~읍니다 | 항상 `~습니다` |
| ~율/률 | 모음·`ㄴ` 받침 뒤는 `율`(비율, 실패율), 그 외 `률`(합격률) |
| ~장이/쟁이 | 기술자는 `장이`(미장이), 속성은 `쟁이`(고집쟁이) |
| ~에요/예요 | 받침 있으면 `이에요`, 없으면 `예요` |
| 잘못된 사동·피동 | `보여지다`, `잊혀지다` 같은 이중 피동 |
| 어간 오분석 | `설레이다`(→설레다), `개이다`(→개다), `푸르른`(→푸른) |

교정부호: `replace`. 이중 피동은 `delete`(뺌표)로 군더더기만 지울 수도 있다.

## O3 조사 오류

| 패턴 | 판정 기준 |
|------|----------|
| 은/는 · 이/가 | 받침 유무. `학교은` → `학교는` |
| 을/를 | 받침 유무 |
| 와/과 | 받침 유무 |
| 에/에게 | 무정물은 `에`, 유정물은 `에게` |
| 로/으로 | 받침 유무(`ㄹ` 받침은 `로`) |

받침 유무 조사는 **완전 결정적**이다. 규칙 계층에서 잡지 못하면 그건 버그다.

교정부호: `replace`.

## O4 사이시옷

순우리말이 든 합성어에서 뒷말 첫소리가 된소리로 나거나 `ㄴ` 소리가 덧날 때 받쳐
적는다. 학생 글에서 자주 나오는 것: 등굣길, 하굣길, 나뭇잎, 빗물, 냇가, 최댓값,
전셋집, 예삿일.

한자어끼리는 원칙적으로 적지 않는다(예외 6개: 곳간·셋방·숫자·찻간·툇간·횟수).

교정부호: `replace`.

## O5 두음법칙·표준어

`년/연`(연도 vs 십 년), `량/양`(수량 vs 구름양), `란/난`(독자란 vs 어린이난) —
앞말이 한자어면 본음, 고유어·외래어면 두음법칙을 따른다.

비표준어: 짜장면/자장면(둘 다 표준), 삐지다/삐치다(둘 다 표준), 넓다랗다(→널따랗다),
어리버리(→어리바리), 구렛나루(→구레나룻).

교정부호: `replace`.

## O6 띄어쓰기

**실측 오류의 50.5%가 여기다.** 가장 큰 덩이이고, 소수의 형태소에 몰려 있다.
기존 `rule_spacing`은 kiwipiepy `space()`의 diff를 그대로 쓰는데, 이것은 방향을
품사로 판정하지 않아 오탐을 낸다. 아래 순서로 결정적 규칙을 얹는다.

| 우선 | 패턴 | 판정 기준 |
|------|------|----------|
| 1 | 의존명사 | `것·거·걸·데·듯·수·시·때·터·뿐·만큼·지·줄`. **앞이 관형형 어미(ETM)면 띄운다.** 실측 신호: `제자리인것` → `…ᆫ/ETM + 것/NNB` |
| 2 | 보조용언 | -어 보다/주다/있다, -게 되다. 원칙 띄어쓰기·허용 붙여쓰기 → **오류가 아니라 권고**(심각도 낮음, `uncertain`) |
| 3 | 접미사 -하다/-되다 | 앞말이 명사(NNG/NNP)일 때만 붙인다. 앞말이 용언 활용형이면 적용하지 않는다 |
| 4 | 조사 | 앞말에 붙인다. `학교 에서` → 붙임표 |
| 5 | 어미 | 어간에 붙인다. `먹었 다` → 붙임표 |
| 6 | 단위명사 | `개·명·번·살`은 띄운다(숫자 뒤 붙임 허용) |

**`하`·`되`·`것`·`한`은 띄우는 오류와 붙이는 오류 양쪽에 나온다.** 형태만 보고 방향을
정하면 절반을 오탐한다. 앞말 품사를 반드시 본다 (`말뭉치_근거.md` 함정 1).

교정부호: `space`(띄움표), `join`(붙임표).

## O7 문장부호

| 패턴 | 판정 기준 |
|------|----------|
| 종결부호 누락 | 문장이 끝났는데 `. ? !`가 없다. **마지막 문장 포함** |
| 물음표 누락 | 의문형 어미(`~까`, `~니`, `~나요`)로 끝났는데 마침표 |
| 따옴표 짝 | 여는 따옴표만 있고 닫는 것이 없다 |
| 쉼표 과다·누락 | 나열에 쉼표가 없거나, 한 문장에 넷 이상 |

교정부호: `punct`(부호 넣음표).

## O8 원고지 형식

| 패턴 | 판정 기준 |
|------|----------|
| 문단 첫 칸 | 문단 시작에서 한 칸을 비우지 않았다 |
| 부호 매달기 | 문장부호가 행 첫 칸에 홀로 앉았다 |
| 줄바꿈 누락 | 화제가 바뀌었는데 한 문단이다 |
| 불필요한 줄바꿈 | 한 문장이 두 문단으로 쪼개졌다 |

교정부호: `indent`(들여쓰기표), `outdent`, `newline`(줄바꿈표), `joinline`(줄이음표).

## O9 외래어 표기

초콜렛→초콜릿, 로보트→로봇, 까페→카페, 메세지→메시지, 컨텐츠→콘텐츠,
악세사리→액세서리, 슈퍼마켙→슈퍼마켓, 화이팅→파이팅.

교정부호: `replace`.

## O10 구어체·통신 표기

`넘`(→너무), `걍`(→그냥), `젤`(→제일), `담`(→다음), `ㅋㅋ`, `ㅠㅠ`, `~^^`,
`쫌`(→좀), `여튼`(→어쨌든).

교정부호: `replace` 또는 `delete`(자모·이모티콘은 뺌표).

## O11 단순 오타 (사전 미등재)

혼동쌍으로 설명되지 않는 순수 오타. `시워하게`→`시원하게`, `마지만`→`마지막`,
`삽인`→`삽입`, `느꼇다`→`느꼈다`.

**실측 표기 오류의 83%가 이 갈래이고, 자모 1개 차이다.** 그리고 같은 (오류→교정) 짝이
두 번 이상 반복된 경우는 0종이었다. 즉 **목록으로는 잡을 수 없다.** 어떤 낱말이 틀릴지
미리 알 필요 없이, 사전에 없는 어절을 찾고 자모 편집거리 1인 표제어를 후보로 낸다.

처방은 **표제어 사전 + 자모 편집거리**다. `unicodedata.normalize("NFD", s)`로 자모를
분해해 거리를 잰다.

**kiwipiepy를 사전 대신 쓰지 않는다.** kiwi는 어떤 입력이든 최선의 분석을 내놓아
"분석 실패"가 나오지 않는다. `초콜렛`을 명사로 받아들이고 `느꼇다`의 없는 어미 `엇`도
그대로 통과시킨다. 실측 근거는 `말뭉치_근거.md` 함정 3.

교정부호: `replace`. 후보가 둘 이상이면 지면에 그리지 말고 `held`로 보낸다.
학생에게 틀린 답을 주는 것이 안 주는 것보다 나쁘다.

## C1~C4 내용 층위 (초점 대상)

| 코드 | 유형 | 예 |
|------|------|-----|
| C1 | 겹말·군더더기 | "미리 예상", "다시 재발" |
| C2 | 상투어·모호어 | "정말 좋았다", "여러 가지" |
| C3 | 주술 호응 | 주어와 서술어가 어긋난다 |
| C4 | 문단 구성 | 한 문단에 두 화제, 화제 전환에 문단 없음 |

이 층은 LLM 계층이 담당하고 지면 상한을 적용한다.

## 오탐 억제 공통 원칙

정확도는 재현율만으로 오르지 않는다. 학생 글에 없는 오류를 표시하면 교사가 신뢰를
잃고 앱 전체를 버린다. 다음은 **오류로 잡지 않는다**.

1. **고유명사·인명·지명** — 사전에 없다고 오류가 아니다. 규칙이 확신하지 못하면
   침묵한다
2. **허용된 복수 표준형** — 짜장면/자장면, 보조용언 붙여쓰기, 숫자+단위 붙여쓰기
3. **인용문 안의 구어체** — 따옴표 안은 인물의 말이다. 표준어로 고치면 글이 죽는다
4. **의도된 반복·강조** — "정말정말"은 문체이지 오류가 아니다. 학년이 낮을수록
   관대하게 본다
5. **kiwi.space() 단독 근거** — 띄어쓰기 교정기는 맞춤법 검사기가 아니다. 확신도가
   낮은 제안은 held로 보내고 지면에 그리지 않는다

각 규칙을 구현할 때 위 5개에 걸리는 입력을 **음성 픽스처**로 코퍼스에 함께 넣는다.
음성 픽스처에서 부호가 나오면 그 규칙은 회귀 실패다.
