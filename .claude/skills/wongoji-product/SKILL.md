# v1 출시 제품 규칙

v1의 사용자는 **초·중등 국어 교사 한 사람**이다. 한 편의 글을 받아 첨삭본을 돌려주는 데 5분을 넘기면 안 된다.

원 기획서(`docs/기획서_원고지첨삭앱.md`)의 1단계가 출시 범위다. 2단계(사진, 회차, 학급, 학부모 발송)는 시범 운영 후에 연다.

## 넣는 것

1. 원고 붙여넣기 (학년, 초점 부호, 간접 첨삭 토글)
2. 규칙 계층 + (있으면) LLM 계층 + 게이트
3. 원고지 SVG 검토: 항목별 승인 / 수정(사유·대체글자) / 기각(되살림표)
4. 총평 3단 편집
5. PNG·PDF 내보내기. 미검토 항목이 있으면 학생용 PDF는 막는다
6. 세션이 프로세스 재시작 후에도 최근 작업을 복구한다
7. LLM 키 없이 규칙 계층만으로 데모가 된다

## 빼는 것

- 점수·등급
- 실시간 타이핑 교정
- OCR / 한글 파일 업로드
- 학급 명단, 로그인 SSO, 멀티테넌트
- hunspell (채택은 리서치에 있으나 v1 경로에 없음)
- Next.js·Supabase 재작성. 엔진이 Python이라 v1은 FastAPI + 바닐라 JS 한 프로세스

## 사용자 여정

```
입력 화면에서 글 붙여넣기
  → 첨삭 실행 (규칙 즉시, LLM은 있으면)
  → 검토 화면에서 부호를 항목과 오가며 승인·수정·기각
  → 총평 손질
  → 학생에게 돌려주기 (PDF) / 첨삭본 PNG
```

교사 승인 없이 학생에게 나가지 않는다. "학생에게 돌려주기"는 미검토 0건일 때만 산다.

## 출시 게이트

통과하지 못하면 출시하지 않는다.

| 게이트 | 판정 |
|--------|------|
| 입력→검토가 UI에서 끝난다 | 데모 문장에 갇히지 않음 |
| `examples/spec_예시.json` 앵커가 기대 칸과 일치 | 레이아웃 테스트 |
| 마지막 문장 종결부호 누락이 잡힌다 | 규칙 계층 |
| 기각된 들여쓰기가 원문을 들여 쓰지 않는다 | export 레이아웃 |
| 파이프라인이 `chumsak_app` 한곳 | 서버가 재조립하지 않음 |
| 점수 문자열이 UI·PDF에 없다 | grep |
| README로 로컬 실행이 된다 | uvicorn 한 줄 |
