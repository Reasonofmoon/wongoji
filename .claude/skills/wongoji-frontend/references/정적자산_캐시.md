# 정적 자산 캐시

`web/app.js`나 `web/app.css`를 고치면 `web/index.html`의 링크에 붙은 내용 해시도
함께 갱신한다. 안 하면 브라우저가 옛 파일을 계속 쓰고, **HTML은 새것인데 JS는 옛것**인
상태가 된다. 새 화면이 뜨지만 아무 동작도 안 하는 증상으로 나타나서, 원인을 코드에서
찾게 된다. 실제로 한 번 겪었다.

```bash
python - <<'PY'
import hashlib, io, re
p = "web/index.html"
s = io.open(p, encoding="utf-8").read()
for name, attr in (("app.css", "href"), ("app.js", "src")):
    h = hashlib.sha1(io.open("web/" + name, "rb").read()).hexdigest()[:8]
    s = re.sub(r'%s="%s(\?v=[0-9a-f]+)?"' % (attr, re.escape(name)),
               '%s="%s?v=%s"' % (attr, name, h), s)
io.open(p, "w", encoding="utf-8").write(s)
PY
```
